Privacy Policy

Effective date: October 3, 2026

1. Who uses WAP Handoff

WAP Handoff is a private tool used only by its owner to synchronize the files of the owner's WAP project with the owner's own Google Drive. It is not offered to the public, has no third-party users and has no user accounts.

2. Google user data accessed

With the owner's authorization, WAP Handoff accesses the owner's Google Drive only to the extent needed for this synchronization: listing, reading, creating and updating the project files and folders it manages in the owner's Drive. It does not access Gmail, Contacts, Calendar or any other Google service.

3. How the data is used

Google Drive data is used only to copy the owner's project files between the owner's computer and the owner's Google Drive. It is not used for advertising, profiling, analytics, or training machine-learning models.

4. Sharing and transfer

No Google user data is sold, shared with, or transferred to any third party. Data moves only between the owner's own computer and the owner's own Google Drive.

5. Storage and security

Files stay in the owner's Google Drive and on the owner's computer. The authorization token is stored only on the owner's computer, in a local configuration file readable only by the owner. WAP Handoff operates no servers and keeps no copy of Google data elsewhere.

6. Retention and deletion

WAP Handoff keeps no separate copy of Google data. The owner can revoke WAP Handoff's access at any time from their Google Account permissions page (myaccount.google.com/permissions), and can delete the synchronized files directly in Google Drive.

7. Compliance

WAP Handoff's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Changes and contact

Any change to this policy will be published on this page with a new effective date. Questions can be raised through the project's GitHub page.
