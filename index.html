WAP Handoff

A private file-sync tool for a single owner.

WAP Handoff is a private tool used only by its owner. It copies the files of the owner's WAP video-production project to the owner's own Google Drive, and reads back the files the project needs from that same Drive.

It is not a public service. There are no user accounts, no sign-ups and no third-party users. Nobody other than the owner uses it.

What it does

  • Uploads project files (for example handoff notes and production files) to a folder in the owner's Google Drive.
  • Lists and downloads files from that folder when the project needs them.

What it does not do

  • It does not access anyone else's Google account.
  • It does not sell, share or transfer Google user data to third parties.
  • It does not use Google user data for advertising.
